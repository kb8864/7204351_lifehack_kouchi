# 七福ライフハック アプリ 独自ドメイン化・AWS移行 予想予算書

- 作成日: 2026年6月21日
- 対象: 七福よさこい連祝禧 運営陣
- 関連: 「AWS移行計画書」

---

## 0. 前提条件

- **利用規模**: 最大150人。特定の人が1日に複数回使うことはあるが、**毎日頻繁ではなく、必要な時にアクセス**するイメージ（=トラフィックは非常に小さい）。
- **期間**: 主に夏の活動期 約6ヶ月を想定。
- **為替**: 1ドル ≒ 155円で換算（2026年時点の概算。実費はレート変動あり）。
- **リージョン**: 東京（ap-northeast-1）想定。
- **「フリーティア」**: AWSは**新規アカウントに限り最初の12ヶ月**、主要サービスに無料枠あり（RDS microなど）。6ヶ月運用はこの期間内に収まる。一部（Lambda・CloudFront等）は**恒常的な無料枠**あり。

> このアプリは規模が小さいため、従量課金（アクセス量に応じる費用）はほぼ無視できます。**費用の主役は「常時起動するデータベースの有無」**です。

## 1. 採用案 A：AWS Amplify ＋ Supabase 据え置き（推奨）

| 項目 | 初期費用 | 月額の目安 | 6ヶ月合計 | 補足 |
|---|---|---|---|---|
| 独自ドメイン（.com等） | 約 ¥1,500/年 | （年額） | 約 ¥750〜1,500 | 年額。6ヶ月按分でも満額でも小額 |
| DNS | ¥0 | ¥0〜80 | ¥0〜480 | Cloudflare/レジストラなら¥0、Route 53なら月約80円 |
| Amplify Hosting | ¥0 | ¥0〜500 | ¥0〜3,000 | 新規アカウントは12ヶ月無料枠で実質¥0の可能性 |
| Supabase（DB） | ¥0 | ¥0 | ¥0 | 無料枠内（※7日未使用で休眠＝初回のみ遅延の可能性） |
| **A案 合計（目安）** | **約 ¥1,500** | **約 ¥0〜600** | **約 ¥1,500〜4,000** | 実質「ドメイン代＋わずかな配信費」 |

- **年額の定常費用（無料枠終了後）**: Amplify 約¥6,000 ＋ ドメイン ¥1,500 ＋ DNS 約¥960 ＝ **約 ¥8,000〜10,000/年**。
- データベースを常時起動しないため、**長期的にも低コスト**で維持できるのが最大の利点。

## 2. 代替案 B：フルAWS（RDS移行、NAT/ALB不使用）

| 項目 | 新規アカウント（無料枠活用） | フリーティア外（定常） |
|---|---|---|
| RDS（PostgreSQL t4g.micro） | ¥0（12ヶ月無料） | 約 ¥2,500/月 |
| ストレージ・バックアップ | ¥0 | 約 ¥500/月 |
| Amplify/Lambda 配信 | ¥0〜 | 約 ¥300〜500/月 |
| 独自ドメイン＋DNS | 約 ¥1,500/年＋¥0〜80/月 | 同左 |
| **6ヶ月合計** | **約 ¥1,500〜5,000** | **約 ¥19,000〜23,000** |
| **年額（定常）** | — | **約 ¥43,000〜46,000/年** |

- 追加で「データ処理の書き換え」と「データベース移行作業（`pg_dump`/`pg_restore`）」の**工数**が必要（AWS料金は不要）。
- ⚠️ **避けるべき構成**（小規模では割高）: Aurora Serverless v2（最低 月約¥6,700〜）、NAT Gateway（月約¥5,000）、ECS＋ALB（ALB 月約¥2,800）。
- 新規アカウントの半年だけ見ればA案と大差ないが、**無料枠終了後の年額がA案の約5倍**になる点が判断材料。

## 3. 参考：最小労力ベースライン（AWSを使わない場合）

| 構成 | 月額 | 6ヶ月 | 備考 |
|---|---|---|---|
| Vercel継続 ＋ 独自ドメイン | ¥0 | 約 ¥750〜1,500 | Vercel Hobby（非商用）は無料。ドメイン代のみ。Next.js 16にも標準対応 |

- 「とにかくお気に入りを守りつつ低コストで」だけが目的なら、**独自ドメインを取得して今のVercelのまま運用**が最安・最小リスク。AWS化は「AWSで持ちたい理由」が出た時に実施でも可。

## 4. 上振れ（追加費用）になり得る要因

| 要因 | 追加費用の目安 | 発生条件 |
|---|---|---|
| Supabase 有料プラン（Pro） | 約 ¥3,900/月 | 7日休眠を避けたい／無料枠（DB 500MB・帯域・MAU）を超過 |

## 5. まとめ・推奨

- **6ヶ月の実費は、A案で「ほぼ独自ドメイン代（約1,500〜4,000円）」**に収まる見込み。
- B案（フルAWS）は新規アカウントの半年なら同程度だが、**無料枠終了後の維持費が高く（年4万円超）**、改修工数も発生するため、今回の規模では **A案を推奨**。
- まず承認いただきたいのは **独自ドメイン取得（年 約1,500円）** のみ。サーバー費用は当面ほぼ発生しません。

> 注: 本書の金額はすべて概算・税抜ベースの目安です。実費はAWS/Supabase/レジストラの最新価格・為替・実利用量により変動します。
